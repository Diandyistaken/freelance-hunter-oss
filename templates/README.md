# Şablon Kütüphanesi — Hızlı Teslim Hattı

Amaç: müşteri hayalini anlatır, biz hazır taslağın üzerinde şekillendiririz.
Teslim süresi günlerden saatlere iner. Her şablon parametrik olacak
(renk paleti, logo, içerik JSON'dan).

Planlanan şablonlar (Faz 4):

| Şablon | Kaynak | Hedef iş |
|---|---|---|
| `3d-scroll-site/` | portfolio'nun scrub altyapısı | 3D/scroll-animasyonlu tanıtım siteleri |
| `business-landing/` | portfolio bileşenleri | Yerel işletme landing page (radar satışı) |
| `ai-brief-bot/` | Daily AI Researcher çekirdeği | "Sektör X için günlük özet botu" işleri |
| `inbox-agent/` | Kisisel Ajan | E-posta otomasyon işleri |
